\# Onboarding Guide (Demo Doc)



Welcome to the Agent Sandbox demo knowledge base.



This is a sandboxed folder used only by the `file\_reader` tool. The agent

can only ever read files from inside `track-b-agent/demo\_docs/` — path

traversal outside this folder is blocked in `tools/file\_reader.py`.



\## Getting started



1\. Your account was provisioned by an admin.

2\. Support tickets can be filed through the `create\_ticket` tool

&#x20;  (high risk — requires approval).

3\. Use `csv\_query` to look up account data (medium risk).
